💾 الحفظ التلقائي والدائم

كل تعديل على الأصناف أو المستودعات أو الموردين أو الوحدات يُحفظ تلقائياً في متصفحك — البيانات تبقى محفوظة حتى بعد إغلاق المتصفح أو إعادة تشغيل الجهاز.

✓ آخر حفظ تلقائي: لم يُحفظ بعد
📂 السجل الأرشيفي — نسخ يمكن استعادتها

احفظ نسخة كاملة من قاعدة البيانات (أصناف + مستودعات + موردين + وحدات) في أي لحظة، ثم استعدها لاحقاً أو نزّلها كملف JSON للنسخ الاحتياطي خارج المتصفح. يُحتفظ بآخر 30 نسخة كحد أقصى تلقائياً، مع نسخة تلقائية صامتة كل 5 دقائق أثناء العمل.

اسم النسخةالتاريخ والوقتالمحتوىاستعادةتنزيل
📊 تقرير مقارنة الأسعار عبر الأرشيف

يقارن سعر شراء كل صنف عبر النسخ الأرشيفية المحفوظة (كل نسخة = لحظة زمنية) مع السعر الحالي، لتتبع ارتفاع أو انخفاض أسعار الموردين بمرور الوقت. احفظ نسخة أرشيفية بعد كل تحديث أسعار حتى يبني التقرير سلسلة زمنية مفيدة.

ℹ️ كيف يعمل الأرشيف؟
  • الحفظ التلقائي الفوري: أي إضافة أو تعديل أو حذف في الأصناف/المستودعات/الموردين/الوحدات يُحفظ مباشرة في متصفحك (localStorage) — يبقى حتى لو أغلقت المتصفح.
  • السجل الأرشيفي (Snapshots): نسخ مُسمّاة يدوياً يمكن العودة إليها — مفيدة قبل عمليات استيراد كبيرة أو تنظيف البيانات.
  • نسخة تلقائية صامتة: كل 5 دقائق أثناء استخدامك للنظام يُحفظ سجل تلقائي بصمت دون إزعاجك.
  • التنزيل والاستعادة: يمكنك تنزيل أي نسخة كملف JSON ونقله لجهاز آخر أو حفظه خارجياً، ثم استيراده لاحقاً لاستعادة البيانات بالكامل.

2️⃣ 🔑 مفتاح API — الإعداد الأول

مطلوب لقراءة بيانات الفواتير من PDF والصور بالذكاء الاصطناعي. أدخله هنا مرة واحدة وسيُزامَن تلقائياً مع الإعدادات.

⚠️ تحذير أمني: هذا المفتاح سري — لا تشاركه مع أحد خارج الفريق ولا تضعه في رسائل أو إيميلات.
🔐 مفتاح Anthropic API — للنسخ والتزامن مع الإعدادات
يُخزَّن في المتصفح فقط — لا يُرسل لأي خادم غير Anthropic مباشرة
✅ تم نسخ المفتاح! — يمكنك الآن لصقه في تبويب ⚙️ الإعدادات أو في أي جهاز آخر.
أو اضغط "💾 حفظ في الدليل والإعدادات" لحفظه مباشرة بدون لصق يدوي

خطوات الحصول على المفتاح (أول مرة):

1
افتح Anthropic Console
console.anthropic.com ← سجل الدخول بحساب المؤسسة
2
أنشئ مفتاحاً جديداً
API Keys ← Create Key ← اسم مثل "Areeka-PO-System"
3
انسخ المفتاح فوراً
يظهر مرة واحدة فقط — الصقه في الحقل أعلاه واضغط 💾 حفظ
4
اختبر الاتصال
اضغط ✅ اختبار الاتصال — يجب أن يظهر "المفتاح يعمل"

4️⃣ الأصناف وأسماء OCR

📌 أسماء OCR هي الكلمات التي تظهر في الفاتورة الممسوحة — افصل بينها بـ |
مثال: جبنة شيدر|cheddar|جبن شيدر|شيدر

كلما أضفت أسماء OCR أكثر، كانت المطابقة التلقائية أدق وأسرع.

💡 يمكن استيراد الأصناف من Excel أودو مباشرة (Internal Reference, Product Name, UOM...)
